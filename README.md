A Project where I followed [Writing an operating system from scratch](OS_Dev.pdf) by the University of Birmingham
I used this project to get a little more knowledge about C and assembly.

If you want to run this project yourself, you need to make sure you have the following depencies installed:
NASM
GCC
qemu
make
gdb
ld

Then it is just a matter of running the make command or the make debug command

Note: On windows make sure you are using the cross compiler
